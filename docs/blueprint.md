# **App Name**: CodeEmbed by carlosguisan

## Core Features:

- Code Editor Interface: Multi-language syntax-highlighted code editor with theme switcher, line numbers toggle, character/line counter, title input, description textarea and 'Make Public' setting.
- Live Preview System: Split view: Light theme preview | Dark theme preview, Real-time syntax highlighting as user types, preview matches final embed appearance, adjustable preview height slider.
- Embed Code Generator: Generate iframe and script tag embed options with copy button and direct link to full-page view.
- Firestore Integration: CRUD operations using Firestore for snippets with user authentication, public/private access, and timestamps.
- My Snippets Dashboard: Display user's saved snippets as cards in a grid layout with search, language filter, sort options, and action buttons (Edit, Delete, Duplicate).
- Embed View Page: Clean, minimal page for iframe embedding with syntax highlighting, copy code button, and increment view count on load.
- Localization: Localization in Spanish

## Style Guidelines:

- Primary color: Deep green (#2d5016) for a professional and coding-related feel.
- Background color: Light green (#e8f5d9) provides a clean, contrasting backdrop.
- Accent color: Lime green (#a3d977) to highlight key UI elements.
- Headings: 'Work Sans' (sans-serif) for titles.
- Body: 'Work Sans' (sans-serif) for text.
- Code: 'Source Code Pro' (monospace) for code snippets.
- Use icons to represent languages, settings, and actions. Preferably in green tones.
- Clean, developer-friendly layout.
- Subtle transitions and animations on interactive elements.
